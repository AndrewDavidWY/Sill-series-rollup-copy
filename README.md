# 品宣设计手册

从海报、X展架和易拉宝的系列文案策划，接续到实际成品设计，再把现有物料整理为客户可检索、可调用、可扩充的品宣应用手册，并交付PDF和可编辑源文件。

原名称为「系列易拉宝文案策划」。安装及调用名称继续使用 `series-rollup-copy`，既有调用不需要更换。此仓库提供中文技能指令，网站的多语言介绍不代表安装包有多个语言版本。

## 三个阶段

| 阶段 | 适用请求 | 主要交付 |
| --- | --- | --- |
| 海报、X展架文案策划 | 先策划一整套、调整信息量、融合新资料 | 系列逻辑、逐张上版文案、设计要求及来源 |
| 成品设计 | 设计第几张、继续下一张、制作整组 | 高清成品、审阅预览、可编辑源及约定的印刷候选文件 |
| 客户手册及源文件 | 像VIS、SI、IP一样做成手册、输出PDF | 品宣应用手册PDF、单件成品、源文件及资源包、索引与核验记录 |

可以只委托其中一个阶段。已有物料直接核对收录；仅文案请求不会自动扩大成制作或印刷服务。

## 准备资料

- 品牌介绍、服务内容、受众与本次传播目标。
- 正式Logo、现行VIS以及可参考的SI、IP或其他品牌手册。
- 现有文案与成品、最近确认的修改，以及用户指定的网址或联系入口。
- 已知的数量、尺寸、发布渠道；制作实物时提供支架或供应商模板。

没有指定配色、张数或手册比例时依据当前资料判断。历史项目的12张海报、8套展架或40页手册只是一次交付范围，不是默认规格。

## 安装与调用

下载完整ZIP并解压，将包含 `SKILL.md`、`agents/` 和 `references/` 的完整文件夹安装为 `series-rollup-copy`。也可克隆：

```sh
git clone https://github.com/AndrewDavidWY/Sill-series-rollup-copy.git ~/.codex/skills/series-rollup-copy
```

使用自定义 `CODEX_HOME` 时放到其 `skills/` 下。已有同名目录先比较差异、保留本机修改；安装后在新会话中确认技能可用。网站下载固定到其显示的源码提交；仓库主分支与待合入更新的状态以GitHub为准。

```text
使用 $series-rollup-copy，根据品牌介绍策划系列海报和X展架。先列整组分工，再写逐张上版文案与设计要求，保留文案依据。
```

```text
根据已确认策划继续设计第3张X展架，沿用前两张的品牌识别和指定网址，交付实际成品、预览与可编辑源文件。
```

```text
使用 $series-rollup-copy，把目前已完成的海报和X展架整理成品宣应用手册，参考现有VIS、SI和IP手册，输出PDF与源文件包。后续还会增加其他物料，请预留扩展结构。
```

## 文件结构

- [SKILL.md](SKILL.md)：阶段选择、共享约定与完成标准。
- [agents/openai.yaml](agents/openai.yaml)：显示名称、简介和默认调用提示。
- [references/copy-planning.md](references/copy-planning.md)：系列逻辑、内容密度、策划交付。
- [references/finished-design.md](references/finished-design.md)：单件制作、不同媒介适配与成品核验。
- [references/manual-delivery.md](references/manual-delivery.md)：可扩展手册、源文件打包、核验与维护。
- [references/lessons.md](references/lessons.md)：从实际协作提炼的通用经验。

## 使用与交付边界

正式Logo、事实、网址和联系方式以当前项目资料为准。AI场景与结构示意不能证明真实项目或业绩；印刷尺寸PDF也不能替代供应商规格确认、实物打样、支架安装和现场扫码。不会自动更换客户VIS，也不将客户素材、原始聊天或私有交付包随公开Skill分发。

方法源自系列展架的文案调整，以及海报、X展架逐张设计和品宣手册交付的实践。本次扩展保留了文案密度与版本连续性的处理经验；不把历史案例的数量、日期、品牌色和本机环境作为通用要求。源码、网站介绍、本机安装和其他电脑副本分别维护。
