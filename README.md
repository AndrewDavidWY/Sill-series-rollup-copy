# 系列易拉宝文案策划

先设计整组展架的阅读逻辑，再写每一张的标题和要点，让观众顺着看就能理解，也让设计师拿到文案后能继续排版。

技能名称：`series-rollup-copy` · [查看技能指令](SKILL.md)

## 适合什么时候用

- 会议或展览需要多张连续阅读的易拉宝。
- 旧会议内容与新参考材料需要融合为一组文案。
- 原稿太满或太空，需要调整文字密度与信息分工。

## 开始前准备什么

- 本次主题、目标受众、数量、尺寸和内容边界。
- 已有文案、参考资料，以及最近确认的版本。
- 希望保留的关键事实、机制和表达风格。

## 工作方式

1. 确认范围，再设计整组展架的叙事顺序。
2. 给每一张分配独立的信息职责。
3. 写主标题、副标题和少量有内容的要点。
4. 根据反馈调整密度，保留已确认内容和版本关系。

## 可以得到什么

- 按顺序编号的整组展架文案。
- 每张明确的标题、具体要点及可选收束语。
- 简短版本表和本次修改范围。

## 安装与调用

将完整仓库克隆到自己的技能目录，安装文件夹使用技能名称 `series-rollup-copy`：

```sh
git clone https://github.com/AndrewDavidWY/Sill-series-rollup-copy.git ~/.codex/skills/series-rollup-copy
```

如果使用自定义 `CODEX_HOME`，请放到其 `skills/` 下。同名目录已经存在时先比较版本并保留自己的修改，不要直接覆盖。下载 ZIP 时，同样需保留完整文件结构，并把解压后的安装目录命名为技能名称。

在新会话中确认技能可用，再用下面的方式提出任务：

```text
使用 $series-rollup-copy，把旧会议材料与新增资料整理为5张系列易拉宝。面向初次了解项目的来宾，先给整组逻辑，再写单张内容；不要只写口号。
```

## 使用边界

张数和结构按本次需求决定，不固定六张。文字策划不自动包含设计图和印刷文件；具体数字、治理机制或资本成果必须有资料支持。
